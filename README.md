# 💫 About Me
Hi, I'm Jaron, a full-stack software engineer and Cal Poly Pomona CS graduate (Dec 2025) based in the Los Angeles area. I build web and mobile apps with React, TypeScript, Node, and Flutter.

Most recently I was a software engineer intern at Meeedly, building reusable React components for dashboard development. At Inkwave, I implemented client-side caching that cut document retrieval latency about 50%. I also published Chordpath, a Flutter guitar-learning app, on Google Play.
